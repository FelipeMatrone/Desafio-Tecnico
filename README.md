## Uso de ferramentas de IA

Durante o desafio, utilizei o Codex como ferramenta de apoio para tirar dúvidas, auxiliar na implementação e revisão do código, organizar os arquivos e elaborar a documentação. Procurei desenvolver as atividades por etapas, pesquisando quando surgiam dúvidas, pedindo explicações e testando as soluções para entender melhor como funcionavam. No backend, por exemplo, testei as requisições da API no Postman.

Um exemplo concreto foi durante o desenvolvimento com Vue, quando utilizei a IA para entender conceitos da Composition API, como `ref`, `computed` e a comunicação entre componentes por props e eventos. Outro momento foi quando apareceu um aviso no `tsconfig.json` do backend, que foi resolvido com a ajuda da IA ao definir explicitamente o `rootDir` como a pasta `src`.

Sobre MCP (Model Context Protocol) e agentes de IA, tenho pouca experiência prática desenvolvendo integrações ou agentes próprios. Já tinha ouvido falar sobre agentes, mas não conhecia muito sobre MCP, então procurei pesquisar por conta própria e também tirar dúvidas com a IA. Pelo que entendi, o MCP é um protocolo que permite conectar aplicações de IA a ferramentas e fontes de dados, como arquivos, APIs e bancos de dados. Os agentes podem utilizar ferramentas para realizar tarefas, enquanto as skills reúnem instruções e recursos que ajudam a orientar atividades específicas. Ainda estou aprendendo sobre esses assuntos, mas são tecnologias que despertaram minha curiosidade, principalmente por estarem relacionadas à área de desenvolvimento de software que estou estudando. Tenho interesse em entender melhor como funcionam e como posso utilizá-las na prática futuramente.
